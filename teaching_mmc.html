Exercice - cercle de Mohr interactif

Tenseur des contraintes (MPa) : tapez une valeur ou déplacez le curseur.

viewof sxy = Inputs.range([-300, 300], {value: 30, step: 1, label: html`σ<sub>xy</sub>`})
c = (sxx + syy) / 2
R = Math.sqrt(((sxx - syy) / 2) ** 2 + sxy ** 2)

theta = 0.5 * Math.atan2(2 * sxy, sxx - syy)
thetaDeg = theta * 180 / Math.PI
e1 = [Math.cos(theta), Math.sin(theta)]
e2 = [-Math.sin(theta), Math.cos(theta)]

{
  const r2 = Math.SQRT1_2;
  const t1 = [r2 * (e1[0] + e2[0]), r2 * (e1[1] + e2[1])];   // cisaillement max (+45°)
  const t2 = [r2 * (e1[0] - e2[0]), r2 * (e1[1] - e2[1])];   // cisaillement max (−45°)
  const smax = Math.max(Math.abs(s1), Math.abs(s2), 1e-9);

  const axe = (n) => [{x: -1.7 * n[0], y: -1.7 * n[1]}, {x: 1.7 * n[0], y: 1.7 * n[1]}];
  // flèches depuis l'origine : sortantes en traction, rentrantes en compression
  const fleches = (n, s) => [1, -1].map(k => {
    const L = 0.35 + 0.75 * Math.abs(s) / smax;
    const p = [k * 0.1 * n[0], k * 0.1 * n[1]];
    const q = [k * L * n[0], k * L * n[1]];
    return s >= 0 ? {x1: p[0], y1: p[1], x2: q[0], y2: q[1]}
                  : {x1: q[0], y1: q[1], x2: p[0], y2: p[1]};
  });

Exercice - rosette de déformation

Une rosette est composée de trois jauges collées selon les angles θa, θb et θc, mesurés depuis l’axe x.

Rosette : angles des jauges (°) et déformations mesurées (µm/m).

rDeg = Math.PI / 180
rRow = t => [Math.cos(t * rDeg) ** 2, Math.sin(t * rDeg) ** 2,
             Math.sin(t * rDeg) * Math.cos(t * rDeg)]
rDet = M => M[0][0] * (M[1][1] * M[2][2] - M[1][2] * M[2][1])
          - M[0][1] * (M[1][0] * M[2][2] - M[1][2] * M[2][0])
          + M[0][2] * (M[1][0] * M[2][1] - M[1][1] * M[2][0])
rSol = {
  const A = [rRow(rTa), rRow(rTb), rRow(rTc)];
  const b = [rEa, rEb, rEc];
  const D = rDet(A);
  if (Math.abs(D) < 1e-6) return null;       // jauges parallèles : système non résoluble
  const col = k => A.map((r, i) => r.map((v, j) => (j === k ? b[i] : v)));
  return {exx: rDet(col(0)) / D, eyy: rDet(col(1)) / D, gxy: rDet(col(2)) / D};
}
rOK    = rSol !== null
rS     = rSol ?? {exx: 0, eyy: 0, gxy: 0}
rC     = (rS.exx + rS.eyy) / 2                          // centre du cercle
rR     = Math.hypot((rS.exx - rS.eyy) / 2, rS.gxy / 2)  // rayon (en ε)
rE1    = rC + rR
rE2    = rC - rR
rGmax  = 2 * rR                                         // distorsion maximale
rTh    = 0.5 * Math.atan2(rS.gxy, rS.exx - rS.eyy)
rThDeg = rTh / rDeg
// point du cercle (ε_n, γ_n) associé à une direction θ
// même convention que l'exercice précédent : la facette x est en (ε_xx, −γ_xy)
rPt = t => {
  const a = 2 * t * rDeg;
  return {s: rC + (rS.exx - rS.eyy) / 2 * Math.cos(a) + rS.gxy / 2 * Math.sin(a),
          t: (rS.exx - rS.eyy) * Math.sin(a) - rS.gxy * Math.cos(a)};
}
rCol = ({bleu: "#3b6ea5", orange: "#d98c2b", violet: "#7b5ea7",
         vert: "#3d8b5f", gris: "#8a94a0"})

Chaque jauge mesure l’allongement dans sa direction :

\[ \varepsilon(\theta) = \varepsilon_{xx}\cos^2\theta + \varepsilon_{yy}\sin^2\theta + \gamma_{xy}\sin\theta\cos\theta \]

Les trois mesures donnent un système de trois équations dont les inconnues sont εxx, εyy et γxy. On en déduit ensuite le cercle de Mohr des déformations et les directions principales.

{
  if (!rOK) return html`<p><em>Choisissez trois directions de jauges différentes.</em></p>`;
  const dir = t => [Math.cos(t * rDeg), Math.sin(t * rDeg)];
  const seg = (n, L) => [{x: -L * n[0], y: -L * n[1]}, {x: L * n[0], y: L * n[1]}];
  const jauges = [["a", rTa, rEa], ["b", rTb, rEb], ["c", rTc, rEc]];
  const e1 = dir(rThDeg), e2 = dir(rThDeg + 90);
  const marks = [
    Plot.ruleX([0], {stroke: rCol.gris}), Plot.ruleY([0], {stroke: rCol.gris}),
    Plot.line(seg(e1, 1.6), {x: "x", y: "y", stroke: rCol.orange, strokeWidth: 2, strokeDasharray: "7,4"}),
    Plot.line(seg(e2, 1.6), {x: "x", y: "y", stroke: rCol.bleu, strokeWidth: 2, strokeDasharray: "7,4"}),
    Plot.text([{x: 1.45 * e1[0], y: 1.45 * e1[1], t: "I"}],
              {x: "x", y: "y", text: "t", fill: rCol.orange, fontSize: 15, fontWeight: "bold", dy: -10}),
    Plot.text([{x: 1.45 * e2[0], y: 1.45 * e2[1], t: "II"}],
              {x: "x", y: "y", text: "t", fill: rCol.bleu, fontSize: 15, fontWeight: "bold", dy: -10})
  ];
  for (const [n, t, e] of jauges) {
    const u = dir(t);
    marks.push(
      Plot.line(seg(u, 0.85), {x: "x", y: "y", stroke: rCol.vert, strokeWidth: 9, strokeOpacity: 0.25}),
      Plot.line(seg(u, 0.85), {x: "x", y: "y", stroke: rCol.vert, strokeWidth: 2}),
      Plot.text([{x: 1.12 * u[0], y: 1.12 * u[1], t: `${n} : ${e} µm/m`}],
                {x: "x", y: "y", text: "t", fill: rCol.vert, fontSize: 12, fontWeight: "bold"})

    marks

Les points verts a, b et c sont les trois jauges : sur le cercle de Mohr, deux jauges séparées d’un angle α dans la rosette sont séparées de 2α sur le cercle. Les droites en pointillés sont les directions principales I et II.
